# White Pooch 🐶

Обучающая математическая игра для детей младшего школьного возраста, разработанная на **Python** с использованием библиотеки **Pygame**.

Игрок управляет белой собачкой, которая прыгает по игровому полю. Для прохождения игровых заданий необходимо решать математические примеры и выбирать правильные ответы.

## Возможности

* главное меню;
* игровой процесс с управлением персонажем;
* математические задания;
* проверка ответов;
* подсчёт игрового результата;
* сохранение лучшего результата;
* графические и звуковые эффекты;
* разделение игровой логики на отдельные компоненты.

## Технологии

* **Python 3**
* **Pygame**
* **ООП**
* **UML**
* **PlantUML**

## Проектирование

Перед реализацией игры была выполнена UML-модель программной системы.

Для описания архитектуры использовался **PlantUML**. Были разработаны:

* диаграмма классов;
* диаграмма компонентов;
* диаграмма объектов;
* диаграмма последовательности;
* диаграмма активностей.

Исходные `.wsl`-файлы с описанием диаграмм и пример объектно-ориентированной реализации представлены в отдельном репозитории:

👉 **[UML-модель White Pooch](https://github.com/vichnya/uml-PlantUML)**

Таким образом, проект включает не только реализацию игры, но и этап предварительного моделирования программной системы.

## Структура проекта

```text
pygame/
├── images/          # изображения и графические ресурсы
├── fonts/           # используемые шрифты
├── sound/           # звуковые ресурсы
├── best_score.py    # работа с лучшим результатом
├── game.py          # основной игровой класс
├── gameplay.py      # игровая логика
├── menu.py          # главное меню
├── questions.py     # математические задания
└── main.py          # точка входа в приложение
```

## Запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/vichnya/pygame.git
cd pygame
```

### 2. Установить Pygame

```bash
pip install pygame
```

### 3. Запустить игру

```bash
python main.py
```
